# Factorio Modeler - Models Directory

## Overview

This directory contains the core data models for the Factorio Modeler simulation system. All models follow C# best practices and represent the fundamental entities: Products, Recipes, Machines, Resources, and Simulation states.

## Subsystems

### Product Models
Models representing entities that can be produced, consumed, or tracked in the simulation.
- **Product** (abstract): Base class for all products with Key and Quantity properties
- **ProductionEntities**: Aggregate production capability across product types
- **ProductionGraph**: Directed graph for production dependency tracking
- **Recipe** (concrete): Craft operation definitions with inputs/outputs
- **RecipeModels**: Collection and validation of recipe data structures
- **Entities**: General entity representation for simulation
- **Machine**: Production equipment with speed and output characteristics

### Data Flow
1. Products → Resources (consumption hierarchy)
2. Resources → Recipes (material requirements)
3. Recipes → Machines (production capacity)
4. Machines → ProductionGraph (dependency resolution)

### Implementation Notes

- All product types inherit from abstract `Product` class
- `ProductType` enum uses bitwise flags for type categorization
- Models are JSON-serializable for configuration persistence
- Speed multipliers and base speeds are calculated dynamically
